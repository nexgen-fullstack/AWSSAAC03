# AWS SAA-C03 — курс і шпаргалка (версія 2) + глибоке навчання

Два сайти українською до іспиту AWS Certified Solutions Architect – Associate (SAA-C03).
Обидва працюють як застосунок на телефоні й офлайн.

- **Курс і шпаргалка** — https://nexgen-fullstack.github.io/AWSSAAC03/ :
  24 уроки з образами, шпаргалка (29 розділів), квіз по тригерах, практичний тест (65 питань),
  схеми і довідник сервісів із підказками.
- **Глибоке навчання** — https://nexgen-fullstack.github.io/AWSSAAC03/deep/ :
  повний курс з нуля — 46 розділів (від основ IT до великої архітектури й розбору іспиту),
  наскрізна історія «Хмаринки», схеми, лабораторії в AWS, 327 питань «Перевір себе»,
  картки для повторення, два пробні іспити по 65 питань (англійською з перекладом),
  словник сервісів і основ IT з підказками прямо в тексті, підручник у PDF.

## Структура

- `docs/` — сайт «Курс і шпаргалка»: `index.html`, офлайн-режим (`sw.js`, `manifest.webmanifest`), іконки, PDF.
- `docs/deep/` — сайт «Глибоке навчання» з власним офлайн-режимом і PDF-підручником.
- `_source/sheet/` — розділи шпаргалки (Markdown).
- `_source/lessons/` — уроки курсу: блоки `===` метадані `===` текст.
- `_source/services.md` — довідник сервісів для підказок (спільний для обох сайтів).
- `_source/questions.md` — питання практичного тесту (пробний іспит 1).
- `_source/build.py` — збирає сайт «Курс і шпаргалка» і його PDF.
- `_deep/chapters/` — розділи глибокого курсу (Markdown з блоками `:::lab`, `:::quiz` тощо).
- `_deep/glossary.md` — словник основ IT і українські форми термінів для підказок.
- `_deep/exam2.md` — пробний іспит 2.
- `_deep/build.py` — збирає сайт «Глибоке навчання», іконки й PDF-підручник; `_deep/PLAN.md` — план і правила стилю.

## Збірка

```bash
python _source/build.py          # курс і шпаргалка
python _deep/build.py --strict   # глибоке навчання (--strict: помилка на битих посиланнях)
```

`--no-pdf` — лише HTML, без PDF (для PDF потрібен Chrome, Edge або Chromium); `_deep/build.py` також має `--no-icons`.

Незалежний навчальний матеріал, не пов'язаний з Amazon Web Services і не схвалений AWS.
Практичні питання — оригінальні, це не реальні питання іспиту.
