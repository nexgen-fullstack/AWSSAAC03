> 🎬 **Історія Хмаринки.** Покупці завантажують фото своїх інтер'єрів з товарами Хмаринки — і хтось уже виклав неприйнятну картинку. Марта щодня вручну переписує дані з сотень PDF-рахунків постачальників. Служба підтримки тоне в дзвінках і відгуках польською, англійською й українською, а Олена хоче знати, **про що** скаржаться. Тарас не має команди data scientists — і не потребує її: більшість таких задач AWS розв'язує **готовими AI-сервісами**, що викликаються одним API-запитом.

> 🖼️ **Образ.** Готові AI-сервіси — це **органи чуття** застосунку. **Rekognition** — очі. **Textract** — бухгалтер, що читає документи. **Comprehend** — читач, що розуміє настрій і сенс тексту. **Transcribe** — вуха (мова → текст). **Polly** — голос (текст → мова). **Translate** — перекладач. **Lex** — співрозмовник. А **SageMaker AI** — лабораторія, де вирощують **власний мозок**, коли готових органів замало. **Bedrock** — бюро найманих «геніїв»: великі генеративні моделі напрокат через API.

## Три рівні AI в AWS {#levels}

| Рівень | Що це | Хто користується | Приклади |
|---|---|---|---|
| **Готові AI-сервіси** | Навчені моделі за API: надсилаєш дані — отримуєш результат | Будь-який розробник, **без знань ML** | Rekognition, Textract, Comprehend, Transcribe, Polly, Translate, Lex, Kendra |
| **Генеративний AI** | Великі базові моделі (foundation models) за API | Розробники застосунків | **Amazon Bedrock** |
| **Платформа ML** | Будуєш, навчаєш і розгортаєш **власні** моделі | Data scientists, ML-інженери | **Amazon SageMaker AI** |

Правило іспиту: якщо задачу можна розв'язати готовим сервісом — обирай **готовий сервіс** (найменше операційних зусиль). SageMaker AI — коли потрібна **своя** модель на своїх даних.

Ще кілька імен, що трапляються у варіантах відповідей:

- **Amazon Personalize** — персональні **рекомендації** в реальному часі («з цим товаром купують…») на основі технологій Amazon.com.
- **Amazon Forecast** — прогноз часових рядів (попит, запаси) і **Amazon Fraud Detector** — виявлення онлайн-шахрайства. ⚠️ Обидва **закриті для нових клієнтів** (Forecast — з 2024, Fraud Detector — з листопада 2025); на іспиті ще можуть бути правильною відповіддю, а в нових проєктах замість них — **SageMaker AI** (зокрема no-code **SageMaker Canvas**).
- **Amazon Augmented AI (A2I)** — **людська перевірка** результатів ML з низькою впевненістю: якщо Rekognition не впевнений щодо фото, воно йде модератору.

## Як AI-сервіси вбудовуються в архітектуру {#patterns}

Готові сервіси — це регіональні API. Їх викликають з Lambda, контейнерів чи серверів через SDK з правами IAM. Три типові конвеєри Хмаринки:

Безпека і приватність AI-сервісів:

- Доступ — через **IAM**; приватний виклик з VPC без інтернету — через **VPC interface endpoints (PrivateLink)**.
- Дані шифруються **KMS**; для записів і документів з персональними даними — **приховування PII** (Transcribe, Comprehend).
- Деякі сервіси можуть використовувати вміст для покращення моделей AWS — від цього відмовляються для всієї організації **політикою AWS Organizations «AI services opt-out»**.
- Якщо модель не підтримує потрібну мову, типовий прийом — спершу **Translate**, потім аналіз.

## Amazon SageMaker AI: власні моделі {#sagemaker}

**Amazon SageMaker AI** (до грудня 2024 — просто Amazon SageMaker; тепер «SageMaker» — ширша платформа даних і AI, а ML-частина зветься SageMaker AI) — повний цикл машинного навчання:

1. **Підготовка даних:** Data Wrangler, **Feature Store** (спільні ознаки для навчання й прогнозів), **Ground Truth** — розмітка даних людьми.
2. **Навчання:** Studio і ноутбуки, **training jobs** на керованих інстансах (зокрема GPU), вбудовані алгоритми, **automatic model tuning**; **managed Spot training** — до 90% дешевше. **Canvas** і **Autopilot** — ML без коду. **JumpStart** — готові моделі, які можна донавчити.
3. **Розгортання (inference)** — чотири варіанти, які люблять на іспиті:

| Варіант | Коли | Особливості |
|---|---|---|
| **Real-time endpoint** | Постійний трафік, потрібна мала затримка | Сервери працюють завжди, автомасштабування |
| **Serverless inference** | Нерегулярний трафік з паузами | Масштабується до нуля, можливий холодний старт |
| **Asynchronous inference** | Великі вхідні дані (до 1 GB), довга обробка (до години) | Черга запитів, результат у S3, може зменшуватися до нуля |
| **Batch transform** | Прогнози для всього набору даних офлайн | Без постійного endpoint: запустив, обробив, вимкнулося |

4. **MLOps:** **Pipelines** (конвеєри навчання), **Model Registry** (версії моделей), **Model Monitor** (дрейф даних і якості), **Clarify** (упередженість і пояснення прогнозів).

## Генеративний AI: Amazon Bedrock {#bedrock}

**Amazon Bedrock** — serverless-доступ до **великих базових моделей** через єдиний API: Anthropic Claude, Amazon Nova, Meta Llama, Mistral та інші. Жодних GPU і серверів — платиш за токени або резервуєш пропускну здатність.

- **Knowledge Bases** — **RAG** (retrieval-augmented generation): модель відповідає на основі **твоїх документів** (S3, бази знань), а не лише загальних знань.
- **Agents** — модель виконує багатокрокові задачі, викликаючи твої API (наприклад, через Lambda).
- **Guardrails** — фільтри шкідливого контенту, заборонені теми, приховування PII.
- **Приватність:** твої запити і дані **не використовуються для навчання** базових моделей; доступ з VPC через PrivateLink; шифрування KMS.

Хмаринка генерує чернетки описів товарів і будує помічника підтримки, що відповідає за правилами доставки й повернення з бази знань.

:::note 🆕 Що з цього на іспиті SAA-C03
Офіційний перелік сервісів SAA-C03 містить **Comprehend, Forecast, Fraud Detector, Kendra, Lex, Polly, Rekognition, SageMaker, Textract, Transcribe, Translate**. Bedrock у ньому немає, але знати його варто: у реальних архітектурах 2026 року він усюди, а питання іспиту поступово оновлюються. Глибше генеративний AI розбирає окремий іспит AWS Certified AI Practitioner.
:::

:::lab 🧪 Спробуй у справжньому AWS: очі, читач і голос за 15 хвилин
**Вартість:** кілька викликів — у межах безкоштовного рівня або центи. **Час:** 15 хвилин. Регіон — **eu-central-1** (Франкфурт).
1. **Rekognition → Label detection** (демо в консолі): завантаж фото кімнати зі свічками — побачиш мітки «Candle», «Furniture» з відсотком впевненості. Відкрий **Content moderation** — так перевіряють фото покупців.
2. **Comprehend → Real-time analysis**: встав англійський відгук «Delivery was late, but the candles smell amazing!» — подивись тональність (найімовірніше **MIXED** — змішана) і сутності.
3. **CloudShell** — те саме з командного рядка, а ще переклад і голос:
```bash
aws translate translate-text --source-language-code uk --target-language-code en \
  --text "Свічки чудові, але доставка затрималася на три дні"
aws comprehend detect-sentiment --language-code en \
  --text "The candles are great, but the delivery was three days late"
aws polly synthesize-speech --output-format mp3 --voice-id Joanna \
  --text "Your order from Khmarynka is on its way!" order.mp3 && ls -l order.mp3
```
Файл `order.mp3` можна завантажити з CloudShell (Actions → Download file) і послухати.
**Прибери за собою:** нічого не створено, крім файлу в CloudShell — видали `order.mp3`.
:::

#### 💡 Запам'ятай

- **Готовий сервіс > власна модель**, якщо задача стандартна: менше зусиль, немає серверів.
- **Rekognition** — фото/відео, обличчя, **модерація**; **Textract** — текст, **форми, таблиці** з документів; **Comprehend** — тональність, сутності, **PII**; **Transcribe** — мова → текст; **Polly** — текст → мова; **Translate** — переклад; **Lex** — чат-боти; **Kendra** — пошук по документах; **Personalize** — рекомендації.
- **Forecast** і **Fraud Detector** закриті для нових клієнтів, але можуть бути в питаннях.
- **A2I** — людина перевіряє сумнівні результати ML.
- **SageMaker AI** — власні моделі: Ground Truth (розмітка), training jobs (**Spot**), Canvas (без коду), inference: **real-time / serverless / async / batch transform**, Model Monitor, Clarify.
- **Bedrock** — базові моделі за API, **Knowledge Bases (RAG)**, Agents, Guardrails; дані не йдуть на навчання моделей.
- Приватність: **PrivateLink**, **KMS**, політика Organizations **AI services opt-out**.

#### 🎯 Як питають на іспиті

- Перевіряти фото користувачів на неприйнятний контент → **Rekognition (moderation)**
- Витягнути поля й таблиці з відсканованих рахунків і форм → **Textract**
- Визначити тональність відгуків або знайти персональні дані в тексті → **Comprehend**
- Розшифрувати записи дзвінків → **Transcribe** (+ Comprehend для аналізу)
- Озвучити текст природним голосом → **Polly**
- Перекласти контент сайту кількома мовами → **Translate**
- Чат-бот для сайту чи кол-центру → **Lex**
- Пошук відповідей по внутрішніх документах природною мовою → **Kendra**
- Власна модель на своїх даних, навчання і розгортання → **SageMaker AI**
- Прогнози для великого набору даних раз на добу, без постійного endpoint → **SageMaker Batch Transform**
- Нерегулярні запити до моделі з паузами, мінімум витрат → **SageMaker Serverless Inference**
- Великі вхідні файли, обробка до години → **SageMaker Asynchronous Inference**
- Людина має перевіряти сумнівні прогнози → **Amazon A2I**
- Заборонити AI-сервісам зберігати контент для покращення моделей у всіх акаунтах → **AI services opt-out policy в Organizations**

#### ⚠️ Пастки

- **Textract** читає документи, а **Rekognition** — зображення загалом (текст на фото він бачить, але не форми й таблиці рахунку).
- **Transcribe** — мова → текст, **Polly** — навпаки. Не плутай.
- **Comprehend** не витягує текст зі сканів — спершу Textract.
- SageMaker AI — не «готовий сервіс»: якщо питають про мінімум зусиль для стандартної задачі, відповідь — відповідний готовий сервіс.

## ✅ Перевір себе

:::quiz
? Соцмережа хоче автоматично виявляти неприйнятні зображення, які завантажують користувачі, з мінімальними операційними зусиллями. Що обрати?
+ Amazon Rekognition з модерацією контенту, викликаний Lambda за подією S3
- Власну модель у Amazon SageMaker AI
- Amazon Textract
- Amazon Comprehend
= Rekognition має готову модерацію зображень і відео. Подія S3 → Lambda → Rekognition не потребує ні серверів, ні власної моделі.

? Бухгалтерія отримує тисячі відсканованих рахунків у PDF і хоче автоматично витягати постачальника, суму і таблицю позицій. Що використати?
+ Amazon Textract
- Amazon Rekognition
- Amazon Comprehend
- Amazon Transcribe
= Textract витягує текст, форми і таблиці з документів, а для рахунків має спеціальний аналіз (AnalyzeExpense).

? Кол-центр хоче аналізувати записи дзвінків: перетворити мову на текст і визначити тональність розмови. Яка комбінація правильна?
+ Amazon Transcribe, потім Amazon Comprehend
- Amazon Polly, потім Amazon Comprehend
- Amazon Transcribe, потім Amazon Rekognition
- Amazon Lex, потім Amazon Translate
= Transcribe перетворює мову на текст, Comprehend аналізує тональність і сутності тексту. Polly робить навпаки — текст у мову.

? Співробітники мають знаходити відповіді на запитання природною мовою у тисячах внутрішніх документів у S3 і SharePoint. Що обрати?
- Amazon Comprehend
+ Amazon Kendra
- Amazon Athena
- Amazon Lex
= Kendra — інтелектуальний пошук по документах компанії з відповідями на запитання природною мовою.

? Модель SageMaker AI щоночі має робити прогнози для 50 мільйонів записів у S3. Постійний endpoint не потрібен. Який варіант розгортання найдешевший?
+ Batch Transform
- Real-time endpoint
- Serverless Inference
- Кілька real-time endpoints з автомасштабуванням
= Batch Transform обробляє весь набір даних офлайн і вимикається після роботи — не треба платити за постійний endpoint.

? Застосунок звертається до моделі кілька разів на годину з довгими паузами. Потрібні мінімальні витрати, невеликий холодний старт допустимий. Що обрати?
- Real-time endpoint на великому GPU-інстансі
+ SageMaker Serverless Inference
- SageMaker Batch Transform щохвилини
- SageMaker Asynchronous Inference з вхідними файлами по 1 GB
= Serverless Inference масштабується до нуля між запитами, тож платиш лише за обробку. Холодний старт — прийнятна ціна за економію.

? Компанія використовує кілька готових AI-сервісів AWS у 40 акаунтах і хоче гарантувати, що контент не зберігається для покращення моделей AWS. Як зробити це найпростіше?
+ Застосувати політику AI services opt-out в AWS Organizations
- Налаштувати SCP, що забороняє всі AI-сервіси
